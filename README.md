# Web Development Portfolio

Moje portfolio web development stworzone w celu prezentowania umiejętności tworzenia stron internetowych.

## O projekcie

Projekt zawiera responsywną wizytówkę internetową z sekcjami:

- Start
- O mnie
- Usługi
- Projekty
- Kontakt
- Formularz kontaktowy

## Technologie

- HTML
- CSS
- JavaScript
- Git
- GitHub Pages

## Funkcjonalności

- responsywny wygląd na komputerze i telefonie
- nawigacja między sekcjami
- efekty hover
- interaktywny formularz kontaktowy
- kontakt telefoniczny
- kontakt e-mail
- prezentacja projektów
